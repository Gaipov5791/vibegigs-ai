# VibeGigs AI

ИИ-ассистент для поиска заказов на фрилансе. Платформа помогает фрилансерам быстрее находить релевантные проекты, отфильтровывать шум и принимать решения на основе данных.

## Идея проекта

VibeGigs AI объединяет сбор заказов с бирж, интеллектуальный анализ и удобное управление в одной системе.

### Парсер

Модуль сбора данных с фриланс-бирж и других источников заказов. Парсер регулярно обновляет базу проектов: заголовки, описания, бюджет, сроки, навыки и ссылки на оригиналы.

### ИИ-агент

Интеллектуальный слой поверх собранных заказов. Агент анализирует проекты, сопоставляет их с профилем и предпочтениями пользователя, ранжирует предложения, выделяет риски и помогает быстрее выбирать подходящие заказы.

### Админка

Панель управления для настройки источников парсинга, правил фильтрации, промптов и поведения ИИ-агента. Через админку можно контролировать качество данных, мониторить работу системы и управлять пользователями.
